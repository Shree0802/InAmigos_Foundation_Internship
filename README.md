# Prathamesh Patil | Personal Profile Website

A responsive, dark-themed personal profile website for an AI/ML student and aspiring full-stack developer. Built with plain HTML, CSS and JavaScript so it can be deployed directly with GitHub Pages.

## Personal photo
The site uses `profile.jpg` in the hero profile card. Keep this file in the same folder as `index.html` when deploying.

## Features
- Responsive layout for desktop, tablet and mobile
- Sections for introduction, about, skills, project themes, learning journey and contact
- Mini profile guide with local demo responses (no API key or backend required)
- Mobile navigation, accessible labels, reduced-motion support and SEO description
- No build step, framework install or environment variables required

## Run locally
Open `index.html` in your browser. For a local server, you can use the VS Code Live Server extension.

## Deploy on GitHub Pages
1. Create a new **public** repository on GitHub, for example `personal-profile-website`.
2. Extract this ZIP and upload the contents of this folder to the repository root. Make sure `index.html`, `style.css` and `script.js` are at the root, not inside an extra nested folder.
3. Commit the files to the `main` branch.
4. Open **Settings → Pages** in the repository.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then click **Save**.
7. Wait a minute or two. GitHub will show the public website URL in the Pages section, usually `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.
